# 🏰 KVK Discord Bot

A Discord bot built to help manage **KingShot KVK preparation, rally coordination, and alliance organization**.

## ✨ Features

- 🏹 Rally leader registration and management
- ⏱️ Rally timing coordination
- 👥 Player management for KVK preparation
- 🔔 Discord-based notifications and commands
- 💾 Redis-powered data persistence

## 🛠️ Tech Stack

- Node.js
- Discord.js v14
- Redis
- JavaScript
- dotenv
